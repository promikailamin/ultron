# Ultron PyTorch training

This directory is the Phase 3/4 pipeline from `ULTRON_FIX_PLAN.md`. It trains a
17M-parameter transformer from scratch, with no pretrained weights or
tokenizers, and exports a checkpoint the Java jar can load directly.

## Local smoke test (CPU, seconds)

```bash
python3 -m pip install -r train_py/requirements.txt
python3 train_py/train.py --smoke --out out/ultron-py-smoke
python3 train_py/export.py --checkpoint out/ultron-py-smoke/best.pt \
    --out out/ultron.bin --vocab-out data
python3 train_py/parity_test.py --checkpoint out/ultron-py-smoke/best.pt \
    --tokenizer-dir out/ultron-py-smoke
```

The smoke test proves the BPE tokenizer, model, export layout, Java fp16 loader
and Python/Java logits agree. It does not produce a useful model.

## Full training (free Colab or Kaggle GPU)

1. Upload or clone the repository and install PyTorch.
2. Train the tokenizer first so a failed training run does not repeat it:

```bash
python3 train_py/bpe.py --corpus data/pretrain.txt --vocab-size 8192 \
    --out out/ultron-py
```

3. Train Stage A and Stage B. The default configuration is 384 wide, 8 layers,
   6 heads, 1536 FFN, 512 context, about 17M parameters.

```bash
python3 train_py/train.py \
    --pretrain data/pretrain.txt \
    --qa data/qa_train.jsonl \
    --eval data/qa_eval.jsonl \
    --out out/ultron-py \
    --steps-a 20000 --epochs-b 4
```

Measure tokens per second from the Stage A log. On a Colab T4 expect hours,
not days. Stage B uses answer-only loss and early-stops when eval loss stops
improving.

4. Export fp16 weights and the BPE files:

```bash
python3 train_py/export.py --checkpoint out/ultron-py/best.pt \
    --out out/ultron.bin --vocab-out data
```

`out/ultron.bin` is about 34 MB for 17M parameters. The Java loader detects the
fp16 magic and converts on load. Commit `data/ultron-vocab.txt` and
`data/ultron-merges.txt` together with the checkpoint.

5. Verify parity and package the jar:

```bash
python3 train_py/parity_test.py --checkpoint out/ultron-py/best.pt \
    --tokenizer-dir out/ultron-py
javac -d build src/*.java
bash .agent-work/tests/chat_smoke.sh
```

## Notes

- `data/qa_train.jsonl`, `data/qa_eval.jsonl` and `data/pretrain.txt` are
  generated by `.agent-work/tools/gen_qa.py`.
- The split is by fact, not by phrasing.
- Do not add pretrained checkpoints, GPT-2 tokenizers or Hugging Face models.
- Check the Minecraft wiki license and attribution before distributing a model
  trained on the wiki extracts.
