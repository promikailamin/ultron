3D is a joke item exclusive to Java Edition 3D Shareware v1.34.


== Obtaining ==


=== Mob drops ===
3D is dropped by Nerd Creepers summoned via the cheat code "NEEEERD".


== Usage ==
Eating the 3D item when the hunger bar is not full shows a picture of the developer cast of Minecraft at the time. Hovering over it in the inventory says "Tasty!" in constantly changing formatting codes.

== Issues ==
Issues relating to "3D" are not maintained on the bug tracker because it is an April Fools' joke, and is therefore not in the newest stable version or snapshot. Issues reported there are closed as "Invalid".
