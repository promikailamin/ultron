Explorer maps are a group of premade map variants which are each marked with a location of one of various structures.


== Obtaining ==
Explorer maps cannot be found in the Creative inventory.


=== Trading ===


=== Generated loot ===
Buried treasure maps can be found in ocean ruins and shipwrecks.
An abandoned camp map can be found in all abandoned camp common chests, and one of seven types of explorer map can be found in all abandoned camp secret chests.


=== Commands ===
In Bedrock Edition, because they are all data variants of the filled map item, they can be obtained with commands such as /give @s filled_map 1 3, but only when it can find a structure to locate. See § Metadata for a list of IDs.
In Java Edition, it is possible to obtain each map using the command /give, varying its ID; however, the maps will be empty. To obtain a map with a structure, it is necessary to use the item modifier exploration_map. Below is the complete list of commands for each map. If the structure is not found, the result will be an empty map. With the exception of the buried treasure map, new maps generated from loot or trades never point to the same structure as previous maps.


== Usage ==


=== Locating structures ===
An explorer map shows a section of terrain that contains a specific structure, marked with a small icon. The structure shown may not be the nearest such structure to the player, the structure depends on when it is graded, where it searches for a structure according to the location of the chest or villager. For loot, the map is generated when the loot is generated (opening the chest, destroying the chest, hopper), for trades, the map is generated when the trade is generated. The structure sought is similar to the command /locate structure but with a range of 101×101 if it is generated by loot (maintain the 201×201 range if it is generated by trading), and ignore the structures that have already been found by previous maps, except for the buried treasure map.
An explorer map differs from a normal map in that it shows the area's land-water outline, with an orange striated texture for water and swamps, and the blank map texture for land.
If the player icon is smaller than it would be on a normal map, that means the player is a great distance away. When the player is less than 1027 blocks away from the map border, the icon returns to the proper size. When the player reaches the map's area of land (512×512), the map fills in like a normal map.
It is possible for multiple maps to point to the same treasure or structure, since explorer maps lead to the closest location (relative to where they were created) of their target type.

The abandoned camp map has 8 variants, each leading to an abandoned camp in a biome they can generate in. They are named "biome Camp Map", except for the bamboo jungle's map, which is named "Bamboo Camp Map". The biomes are: 

Bamboo Jungle
Birch Forest
Cherry Grove
Dappled Forest
Flower Forest
Pale Garden
Swamp
Windswept Forest
An abandoned camp never generates an explorer map for an abandoned camp of the same biome where the chest was generated. If an abandoned camp cannot be found outside of the biome the map was found in, no map is generated.


=== Cloning ===

The parts of the world that have already been explored and mapped are copied, and newly explored areas appear on both instances. In Creative mode, cloned explorer maps can be obtained by pick blocking on the explorer map displayed on item frames (the map needs to be out of the player's inventory when using pick block, or else that map moves into the active hotbar slot).

=== Item data ===
Java Edition:

An explorer map differs from a map in that its map_color and item_name components are set. Additionally, its map_decorations component includes an entry for its target structure. Its map item entry is identical to that of a normal map, except that by the time the player sees it, its colors byte array is pre-filled with explorer maps' characteristic land-water boundary lines and water shading.

== Trivia ==
Explorer maps fill as the chunks are generated, rather than when the player holds them while in the area; leaving an explorer map while exploring the area still fills the map.
In Bedrock Edition, inventory editors and add-ons can be used to create explorer maps that lead to any structure.
