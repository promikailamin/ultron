Purpur blocks are decorative blocks that can be crafted with popped chorus fruit and are naturally generated in End cities and End ships.


== Obtaining ==


=== Breaking ===
The suitable tool to break purpur blocks is a pickaxe. Using any other tool increases the breaking time and the block drops nothing.


=== Natural generation ===
Purpur blocks can be found naturally as part of End cities and End ships.


=== Crafting ===


== Usage ==
Purpur blocks are primarily decorative blocks, similar to other brick-type blocks. They can also be used to craft different variants of the block.

== Trivia ==
Purpur is a specific shade of purple in multiple languages, including Swedish, Polish, German, and Cornish (and French pourpre).
Mojang has associated purpur blocks with the expensive Tyrian purple dye of antiquity, made from the secretions of sea snails.
Purpurite is also a real-world manganese phosphate mineral that has a purple hue.
