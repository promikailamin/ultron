A copper trap is a joke block exclusive to 26w14a.


== Obtaining ==


=== Breaking ===
Although the copper trap has a drop, no vanilla tool is suitable for breaking it, so breaking it with any tool has no effect. Furthermore, attempting to use Attack / Mine to order a tool to mine it does not happen, as tools break only the blocks that they can mine. However, it is still possible to make a copper trap block drop a living copper trap with an explosion.
Using cheats, it is possible to create a tool capable of mining it by modifying minecraft:tool.rules data component. It can also be added to the tag #mineable/pickaxe so that it can be mined by any pickaxe (additionally, adding a tag like #needs_iron_tool prevents it from being mined by some pickaxes.)


=== Post-generation ===
If at least eight living copper bars of the same variant come close together, a living copper trap of that variant forms.
It can be placed as an item in a container by approaching a living container or using a hopper.


== Usage ==


=== Oxidation ===
Unlike most copper blocks, copper traps cannot change their oxidation or wax state. However, unwaxed copper traps continue to slow or prevent the oxidation of nearby unwaxed copper blocks. This behavior is common to all unwaxed copper blocks (see Oxidation § Blocks), but due to the fact that copper traps do not oxidize, they may fully prevent the oxidation of nearby copper blocks at the same oxidation level.
Waxed copper traps have no effect on nearby copper blocks.


=== Trap ===
Living copper traps attempt to pathfind toward the nearest player. When coming in contact with a player, it spawns a cage of 25 copper bars of the same variant of the copper trap around them, trapping them. The copper bars replace all blocks that were previously in the copper bars' positions, including otherwise unbreakable blocks.

== Issues ==
Issues relating to "Copper Trap" are not maintained on the bug tracker because it is an April Fools' joke, and is therefore not in the newest stable version or snapshot. Issues reported there are closed as "Invalid".


== Trivia ==
According to one of the developers, copper and iron traps are a reference to the mod SecurityCraft.
